# Password Manager

Простое и удобное настольное приложение для управления паролями, написанное на Python.
Позволяет генерировать надежные пароли, проверять их сложность и сохранять данные локально.

## Возможности

- 🎲 **Генерация паролей**: Создание случайных паролей с настройкой длины и используемых символов (цифры, спецсимволы).
- 🛡️ **Анализ безопасности**: Автоматическая оценка надежности пароля (Weak / Medium / Strong).
- 💾 **Локальное хранилище**: Сохранение учетных данных (сервис, логин, пароль) в файл формата JSON.
- 👁️ **Просмотр базы**: Удобное окно для просмотра всех сохраненных записей.

## Требования

- Python 3.8 или выше
- Библиотека `tkinter` (обычно идет в комплекте с Python)

## Структура проекта

Приложение разделено на независимые модули:
- `src/gui` — Отвечает за отрисовку интерфейса.
- `src/logic` — Содержит основную логику (генератор, валидатор, работа с файловой системой).
