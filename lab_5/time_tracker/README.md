# ⏱️ Хронометраж PRO

Современное десктопное приложение для учета времени и анализа продуктивности. Сочетает в себе ручной таймер задач и автоматический трекинг активности активных окон Windows.

![Python](https://img.shields.io/badge/Python-3.10%2B-blue)
![GUI](https://img.shields.io/badge/UI-CustomTkinter-green)
![Status](https://img.shields.io/badge/Status-Active-brightgreen)

## ✨ Возможности

*   **Ручной таймер**: Классический трекер задач (Start/Stop) с историей и возможностью редактирования.
*   **Авто-трекинг**: Фоновый мониторинг активных приложений (браузеры, IDE, игры).
*   **Аналитика**: Визуализация статистики за день в виде диаграммы (Donut Chart) и детального списка.
*   **Работа в фоне**: Сворачивание в системный трей (System Tray) без остановки таймеров.
*   **Современный UI**: Темная тема, адаптивный интерфейс, красивые авто-генерируемые иконки приложений.
*   **Persistance**: Все данные сохраняются в локальную базу данных SQLite.

## 📂 Структура проекта

Проект построен по модульной архитектуре с разделением ответственности (Data, Core, UI).

```text
time_tracker/
├── main.py                     # 🚀 Точка входа в приложение
├── requirements.txt            # Список зависимостей
├── README.md                   # Документация
│
└── app/
    ├── config.py               # Глобальные настройки (пути, константы UI)
    │
    ├── core/                   # 🧠 ЯДРО (Бизнес-логика)
    │   ├── controller.py       # Связывает UI и Данные, управляет потоками
    │   └── monitor.py          # Фоновый процесс слежения за активным окном
    │
    ├── data/                   # 💾 ДАННЫЕ
    │   ├── database.py         # Обертка над SQLite (CRUD операции)
    │   └── models.py           # Dataclasses (TimeEntry)
    │
    └── ui/                     # 🎨 ИНТЕРФЕЙС
        ├── main_window.py      # Главное окно, инициализация трея
        └── tabs/               # Компоненты вкладок
            ├── timer_tab.py    # Вкладка 1: Ручной таймер и история
            └── stats_tab.py    # Вкладка 2: Графики и статистика
```
## 🛠 Установка и запуск

1. **Клонируйте репозиторий** (или скачайте архив):

```bash
git clone https://github.com/your-username/time-tracker-pro.git
```
2. **Создайте виртуальное окружение** (рекомендуется):
```bash
# Windows
python -m venv venv
venv\Scripts\activate

# Mac/Linux
python3 -m venv venv
source venv/bin/activate
```
3. **Установите зависимости:**
```bash
pip install -r requirements.txt
```

4. **Запуск приложения:**
```bash
python main.py
```
# ⚙️ Технологический стек

*   **CustomTkinter**: Современная обертка над Tkinter для красивого UI.
*   **Matplotlib**: Отрисовка графиков статистики.
*   **SQLite**: Встроенная база данных (не требует установки сервера).
*   **Psutil & Ctypes**: Взаимодействие с Windows API для определения активных процессов.
*   **Pystray & Pillow**: Работа с системным треем и генерация иконок.

# 🖥 Использование

1.  **Вкладка "Таймер задач":**
    *   Введите название задачи.
    *   Нажмите **"Старт"** для начала отсчета.
    *   Нажмите **"Стоп"**, чтобы сохранить запись в историю.
    *   Записи можно редактировать (✎) или удалять (✕).

2.  **Вкладка "Авто-трекинг":**
    *   Приложение автоматически следит за тем, какое окно активно.
    *   Нажмите **"Обновить данные"**, чтобы увидеть круговую диаграмму и список топ-приложений за сегодня.

3.  **Системный трей:**
    *   При нажатии на крестик окно **не закрывается**, а сворачивается в трей (иконка возле часов).
    *   *ПКМ по иконке*: Меню "Открыть" или "Выход".
